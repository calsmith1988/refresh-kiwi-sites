Intended use

01

Write freely

Use example.com in books, slides, and API docs when you need a domain that will never conflict with a real service.

02

Illustrate clearly

Show URL patterns, DNS records, and configuration snippets with a hostname everyone recognizes as fictional.

03

Stay non-operational

Do not build applications that depend on this domain for production traffic. Incidental misconfiguration is expected; designed dependency is not.

A domain with one job

“These domains may be used as illustrative examples in documents without prior coordination.”

— IANA Example Domains

Example Domain is not a company, product, or service. It is infrastructure for clarity — a blank label on the internet’s shelf, ready whenever a writer needs a harmless address to point at.
