Where it belongs

Built for documentation, not production traffic.

Writers, educators, and engineers need a neutral hostname when illustrating URLs, DNS records, and web standards. Example Domain is deliberately unremarkable — and permanently reserved for that purpose.

API & SDK docs

Sample endpoints, webhook payloads, and auth flows without pointing at real services.

DNS & networking

Zone files, resolver examples, and certificate tutorials with a hostname everyone recognizes.

Standards & RFCs

Neutral references in protocol specs, textbooks, and training material — no trademark risk.

Trust & governance

Operated by IANA, reserved for illustration.

Example Domain is administered by the Internet Assigned Numbers Authority. It exists so documentation can show realistic URLs without routing readers to unknown or third-party sites.

  • Operator Internet Assigned Numbers Authority
  • Intended use Illustration and documentation only
  • Production traffic Not permitted — avoid use in operations

Before you publish

Use it freely in docs.
Keep it out of production.

Cite example.com and example.org in tutorials, slides, and sample code. Do not configure live systems, marketing campaigns, or customer-facing products to depend on this domain.
